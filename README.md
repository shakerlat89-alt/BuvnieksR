# BuvnieksR — Android / Kotlin / Material 3

Полноценный локальный Android-проект на Kotlin по мотивам загруженного PWA-примера BuvnieksR.

## Что реализовано

- учёт сотрудников с именем, ставкой, должностью, специализацией, телефоном и заметками;
- табель за выбранный день: `Был → Полдня → Не отмечен`;
- расчёт зарплаты за выбранный месяц;
- авансы, выплаты и штрафы;
- карточка сотрудника с операциями за месяц;
- быстрые действия через `GridLayout` на главном экране;
- сводка: фонд за день, месячный фонд, начислено, выдано, штрафы, остаток к выплате;
- звонок сотруднику через системный dialer;
- экспорт CSV и резервная копия JSON через системное меню «Поделиться»;
- импорт JSON-резервной копии;
- светлая/тёмная тема Material 3;
- локальное хранение через `SharedPreferences`;
- бизнес-логика вынесена в `ViewModel`, состояние публикуется через `LiveData`.

## Версии

- `compileSdk 34`
- `targetSdk 34`
- `minSdk 24`
- Kotlin `1.9.22`
- Android Gradle Plugin `8.2.2`

## Открытие

Откройте корневую папку `BuvnieksR` в Android Studio и выполните Gradle Sync. Проект намеренно не зависит от серверной БД.

## Важное замечание по проверке

В рабочем окружении был выполнен структурный и синтаксический контроль XML/Kotlin. Полная Android Gradle-сборка в данном runtime не выполнялась, поскольку Android SDK/Gradle toolchain здесь не установлен. Поэтому ZIP содержит исходный проект, готовый для сборки в Android Studio с указанными версиями.
